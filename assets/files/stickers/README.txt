================================================================================
Vessert Sticker Pack & Die-Cut Assets
================================================================================

Overview:
---------
This directory contains production-ready 256x256 high-resolution PNG stickers
and vector badge assets designed for chat messages, reactions, stories, and
interactive messaging overlays.

Specifications:
---------------
- Resolution: 256 x 256 px

- Rendering Engine: @resvg/resvg-js Rust-based SVG rasterizer
