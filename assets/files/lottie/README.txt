Lottie JSON Vector Animation Suite

Overview
Lightweight JSON vector animations formatted to Lottie 5.5.7 specifications for micro-interactions and status states.

Subdirectories
feedback: Reaction and celebration animations (Like, Love, Clap, Confetti, etc.)
loading: Smooth loader spinners, dots, and progress meters
empty: Visual animations for empty content and disconnected states
status: Operation outcomes (Success, Error, Warning, Verified, etc.)
interaction: Gesture guidance animations (Swipe, Pull, Tap, Scroll, etc.)
