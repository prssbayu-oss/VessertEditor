Vessert Vector Illustration Suite

Overview
Bespoke vector SVG illustrations categorized into onboarding, empty states, error codes, and platform features.

Categories
onboarding: 12 onboarding user journey illustrations
empty: 10 state illustrations for empty feeds, chats, searches, and lists
error: 10 HTTP and connectivity error illustrations (400, 401, 403, 404, 500, 503, etc.)
feature: 15 product and social media feature cards
